Se investigaron las definiciones de inteligencia, inteligencia artificial y sistema experto. Con esos resultados se preparó una presentación sobre sistemas expertos (conocimiento, base de conocimiento, motor de inferencia, línea de tiempo y tipos), un guion para el video de exposición y un artículo sobre el estado del arte de la IA.
